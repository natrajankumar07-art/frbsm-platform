## How to Capture

1. Start the platform: `docker compose up -d && open http://localhost:3000`
2. Click "Launch Demo" to enter demo mode
3. Use your browser's screenshot tool or `Cmd+Shift+4` on macOS
4. Save at 1920×1080 resolution, 100% zoom

Screenshots are not committed to source control; they are captured fresh for each demo.
